# Mentava × Sikkim Phonics

A single-page website for the Mentava × Sikkim Phonics Initiative.

## Preview locally

Open `index.html` in a web browser.

## Connect the contribution button to Google Forms

In `index.html`, find the comment beginning with `Replace this mailto URL`. Replace the `mailto:` value in the link immediately below it with the published Google Form URL.

Until then, the button opens a pre-filled email contribution so submissions are not silently lost.
